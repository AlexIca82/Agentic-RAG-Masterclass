# Module 2: BYO Retrieval + Memory

**Complexity:** 🔴 **Complex** - Multiple interdependent components

## Overview

Build the core RAG pipeline: document ingestion, chunking, embeddings, vector storage, retrieval, and chat history management. This module transitions from managed RAG to owning the full pipeline.

## Architecture

```
User Upload → Supabase Storage → Chunking → Embeddings → pgvector
                                                        ↓
Chat → Query Embedding → Vector Search → Context → LLM → Response
                                    ↓
                              Thread/Message Storage
```

## Database Schema

### threads
```sql
CREATE TABLE threads (
  id UUID PRIMARY KEY DEFAULT gen_random_uuid(),
  user_id UUID REFERENCES auth.users NOT NULL,
  title TEXT,
  created_at TIMESTAMPTZ DEFAULT NOW(),
  updated_at TIMESTAMPTZ DEFAULT NOW()
);
```

### messages
```sql
CREATE TABLE messages (
  id UUID PRIMARY KEY DEFAULT gen_random_uuid(),
  thread_id UUID REFERENCES threads ON DELETE CASCADE NOT NULL,
  role TEXT NOT NULL CHECK (role IN ('user', 'assistant', 'system')),
  content TEXT NOT NULL,
  created_at TIMESTAMPTZ DEFAULT NOW()
);
```

### documents
```sql
CREATE TABLE documents (
  id UUID PRIMARY KEY DEFAULT gen_random_uuid(),
  user_id UUID REFERENCES auth.users NOT NULL,
  filename TEXT NOT NULL,
  file_path TEXT NOT NULL,
  file_size INTEGER,
  mime_type TEXT,
  status TEXT DEFAULT 'pending',
  created_at TIMESTAMPTZ DEFAULT NOW(),
  updated_at TIMESTAMPTZ DEFAULT NOW()
);
```

### chunks
```sql
CREATE TABLE chunks (
  id UUID PRIMARY KEY DEFAULT gen_random_uuid(),
  document_id UUID REFERENCES documents ON DELETE CASCADE NOT NULL,
  user_id UUID REFERENCES auth.users NOT NULL,
  content TEXT NOT NULL,
  embedding VECTOR(768),
  metadata JSONB DEFAULT '{}',
  created_at TIMESTAMPTZ DEFAULT NOW()
);

CREATE INDEX ON chunks USING ivfflat (embedding vector_cosine_ops);
```

## Components

### 2.1 Database Setup
- Create Supabase migration with tables
- Enable pgvector extension
- Set up Row-Level Security (RLS) policies

### 2.2 Document Ingestion (Backend)
- POST /api/documents - Upload file to Supabase Storage
- GET /api/documents - List user's documents
- DELETE /api/documents/{id} - Remove document and chunks

### 2.3 Chunking Service
- Text splitter with configurable chunk size (default 512 tokens)
- Overlap between chunks (default 50 tokens)
- Preserve metadata (source, position)

### 2.4 Embedding Service
- Use nomic-embed-text via Ollama (or OpenAI text-embedding-3-small)
- Batch embedding for efficiency
- Store in pgvector

### 2.5 Retrieval Service
- Cosine similarity search
- Configurable top-k results
- Return context with sources

### 2.6 Chat History
- POST /api/threads - Create thread
- GET /api/threads - List threads
- GET /api/threads/{id}/messages - Get thread messages
- Store all messages in database

### 2.7 Frontend Ingestion UI
- Drag-and-drop file upload
- Processing status indicator
- Document list with delete

## Environment Variables

Add to backend/.env:
```
EMBEDDING_MODEL=nomic-embed-text
EMBEDDING_DIMENSION=768
CHUNK_SIZE=512
CHUNK_OVERLAP=50
```

## Validation Tests

1. Upload a text file → appears in documents list
2. File is chunked and embedded → chunks exist in DB
3. Query returns relevant chunks → retrieval works
4. Chat uses retrieved context → RAG pipeline complete
5. Messages persist across sessions → history works
