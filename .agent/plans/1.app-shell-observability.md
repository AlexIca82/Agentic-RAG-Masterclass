# Module 1: App Shell + Observability

**Complexity:** 🔴 **Complex** - Break into sub-plans before executing

## Overview

Build the foundational app shell with authentication, chat UI, and Ollama integration. This module establishes the core architecture that subsequent modules will extend.

## Prerequisites

- [ ] Supabase project created (get URL and anon key)
- [ ] Ollama installed and running with mistral-3:8b-cloud model
- [ ] Node.js 18+ installed
- [ ] Python 3.11+ installed

## Architecture

```
agentic-rag/
├── frontend/           # React + Vite + TypeScript
│   ├── src/
│   │   ├── components/  # UI components
│   │   ├── lib/         # Utilities
│   │   ├── pages/       # Page components
│   │   └── hooks/       # Custom hooks
│   └── ...
├── backend/            # Python + FastAPI

│   │   ├── core/        # Config, security
│   │   ├── models/      # Pydantic models

└── .agent/
    └── plans/
```

## Sub-Plans

### 1.1 Backend Setup (`1.1.backend-setup.md`)
- Python venv setup
- FastAPI application structure
- Environment configuration
- Supabase client setup
- Health check endpoint

### 1.2 Frontend Setup (`1.2.frontend-setup.md`)
- Vite + React + TypeScript project
- Tailwind CSS configuration
- shadcn/ui installation
- Base layout components
- API client setup

### 1.3 Authentication (`1.3.authentication.md`)
- Supabase auth integration (backend)
- Auth middleware for protected routes
- Login/signup UI components
- Session management
- Protected route wrapper

### 1.4 Chat UI (`1.4.chat-ui.md`)
- Chat message components
- Message input with send button
- Thread display
- Streaming response handling (SSE)
- Ollama integration via Chat Completions API

### 1.5 Observability (`1.5.observability.md`)
- RAGAS setup for evaluation
- Basic logging configuration
- Request/response tracking

## Validation Tests

1. **Backend Health**: `curl http://localhost:8000/health` returns 200
2. **Frontend Loads**: Navigate to `http://localhost:5173` shows login page
3. **Auth Flow**: User can sign up, log in, log out
4. **Chat Works**: User can send message and receive streaming response from Ollama
5. **Protected Routes**: Unauthenticated users redirected to login

## Environment Variables

### Backend (.env)
```
SUPABASE_URL=your_supabase_url
SUPABASE_ANON_KEY=your_supabase_anon_key
SUPABASE_SERVICE_ROLE_KEY=your_service_role_key
OLLAMA_BASE_URL=http://localhost:11434
OLLAMA_MODEL=mistral-3:8b-cloud
```

### Frontend (.env)
```
VITE_SUPABASE_URL=your_supabase_url
VITE_SUPABASE_ANON_KEY=your_supabase_anon_key
VITE_API_URL=http://localhost:8000
```
